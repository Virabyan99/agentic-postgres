## Call `init()` first

```ts
const client = createClient({ restUrl, appUrl, token });
const started = await client.init();
if (started.kind !== "ok") throw new Error(started.kind);
```

`init()` fetches the REST service's own OpenAPI document **as you**, normalizes
it the way this project's capture does, and compares the fingerprint to the one
embedded in `contract.ts`. Until it answers `ok`, every other method returns
`{ kind: "not_initialised" }`.

It has four answers, and the difference between them matters:

| answer | what it means |
|---|---|
| `ok` | the service is serving the surface this client was generated from |
| `stale_contract` | it is serving a *different* surface — both digests are named |
| `unreachable` | the service did not answer; nothing is known about its surface |
| `unparsable` | it answered something that is not that document |

`unreachable` is never reported as `stale_contract`. A client that could not
reach a service knows nothing about its contract, and saying otherwise would
send you to re-capture a snapshot that was already right.

## What this client holds

Only what you gave it. No credential, no URL, no key is generated into any file
here; the token lives in a closure and never reaches a URL, a log or an error.
Nothing in this package prints.
