# Agentic Postgres

Your team's own PostgreSQL 18 projects, with pgvector, on one hosted server. Each project has a pooled and a direct connection, both over TLS; a branch is a full copy you can restore to a point in time; backups run continuously off-site, and the console shows the window you can restore to.

During the beta every organisation is on the Free plan, at no cost. [Pricing](/pricing/) lists what each plan allows, and [What exists](/ledger/) lists every concept this product names with what it is today -- generated from the same file the product checks itself against.

## Request an invitation

The beta is invite-only: there is no public signup. To ask for an invitation, [write to invite@agenticpostgresql.com](mailto:invite@agenticpostgresql.com?subject=Invitation%20request) and say who you are and what you would build. The invitation arrives as a link; opening it creates your account.

## Start

- [Quickstart](/quickstart/): from the invitation link to a working connection string.
- [Documentation](/docs/): connecting, branches, backups, plans and usage, Query Insights and monitoring, the command-line client.
- [Open the console](https://control.agenticpostgresql.com/console/) if you already have an account.

Something here wrong or missing? Write to [invite@agenticpostgresql.com](mailto:invite@agenticpostgresql.com).
