What every project gives you

Four things, each running today. The limits are on the same page as the feature, not in a footnote.

Two connections, both over TLS

In the beta

The pooled door is your application's transaction pooler. The direct door is a session pooler as the administrator, for migrations. Both on port 5432 with sslmode=verify-full.

Branches you can restore to a moment

In the beta

A branch is a full copy restored from the project's own backups, with its own two passwords and its own two addresses. Pick any moment inside the backup window and it becomes a new branch.

A branch is not backed up. One branch per project on the Free plan.

Read Branches

Continuous off-site backups

In the beta

Backups stream to off-site object storage, with a nightly copy to a second provider. The console shows the restore window and how recently it was read, and gives the reason when it could not be read.

A sleeping project's backups stop. Its last restore point is the moment it went to sleep.

Read Backups

Numbers that name their source

In the beta

Query Insights gives each normalised statement's calls, time, rows and cache hit ratio. Monitoring is a short list of readings, each with its age and where it came from. A figure that could not be read is said, never shown as zero.
