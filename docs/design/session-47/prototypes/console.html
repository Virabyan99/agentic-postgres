New project

A PostgreSQL 18 database with its own API, backups and two connection doors.

What a project includes
Letters, numbers, spaces, dots, dashes. Only you see it.
The first user of the project's own sign-in (its API), not your console account.
You can change it later in Settings.

What happens next

Creating a project usually takes 23 to 28 minutes. Most of that is the first full backup, which makes sure your data can be restored from the start.

You can close this page. The project shows on Projects while it is being created, and Notifications tells you when it is ready.

Save the administrator's handoff token now, if you want it

This token lets someone using the command line take over the project's administrator account (ana). You do not need it to connect, from the console or from your application. It is shown once, now, and never again.

Save the token to a file only you can read, then, once the project is ready, run:

      Settings
      How notes-app runs, and what to do when you need help with it.
      Settings, in the docs
      
      
      
        
      Idle sleep Whole project
      Stop the project after this long without connections. The next connection wakes it in about 20 seconds.
      
        
      Size Whole project
      small: the database's memory and CPU share on this server. Changing it restarts the project for a few seconds.
      
        
      Sleep now
      Stop it until you wake it. Your data and connection strings stay the same.
      
        
      Export
      A full dump of the database you can download for 24 hours.
      
        
      Support bundle
      A file with the project's health checks and recent operations, and no data or passwords. Send it with a support request.
      
      
      
      
      
        
      Delete notes-app
      
        
      Deletes the database, its branches and its backups. This cannot be undone. Your plan's project becomes free again.
      
        
      
      
      
      
        
      
          
      Delete notes-app?
      
          
      Everything in it is deleted: the database, its branches and its backups.
